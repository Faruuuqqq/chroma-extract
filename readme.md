# ChromaExtract - ACHMAD FARUQ MAHDISON - 140810240080

**ChromaExtract** is a modern color palette generator built with Python and Streamlit. It uses Machine Learning (K-Means Clustering) to extract the most dominant and beautiful colors from any uploaded image.

## ✨ Features
- **AI-Powered Color Extraction**: Upload any image (JPG, PNG, WEBP) and let K-Means clustering find the primary color themes.
- **Premium UI/UX**: Enjoy a sleek, responsive "Light Mode" design with modern typography (Plus Jakarta Sans & JetBrains Mono) and interactive "Ribbon" color cards.
- **Multiple Export Options**: Easily copy your extracted colors in **HEX**, **CSS variables**, or **JSON** format.
- **Educational Visualization**: Learn how the algorithm works under the hood! Includes a 3-step breakdown and an advanced 2D scatter plot showing exactly how pixels are distributed and clustered.

## 🛠️ Built With
- [Streamlit](https://streamlit.io/) - Web framework
- [Scikit-Learn](https://scikit-learn.org/) - K-Means Clustering Algorithm
- [Pillow (PIL)](https://python-pillow.org/) - Image processing
- [Matplotlib](https://matplotlib.org/) - Advanced data visualization
